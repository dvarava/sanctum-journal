# Sanctum Journal

Sanctum Journal is a privacy-focused desktop journaling app built with Go, Wails, React, TypeScript, and SQLite. It stores journal entries locally in an encrypted vault and supports local AI-assisted reflection through Ollama, with crisis-safety checks and simple trend views.

A downloadable macOS build is available on the project website:

https://dvarava.github.io/sanctum-journal-website/
